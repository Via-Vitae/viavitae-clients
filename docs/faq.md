# FAQ — For parish staff and content editors

## How do I request a new website?

Open a GitHub issue using the "New client onboarding" form. You will need:
- The official name of your organisation
- Your preferred web address (domain)
- An admin email address
- Which package tier you need (economy, normal, or vip)

## How do I update content on our website?

1. Contact your account manager or open a "Tenant change request" issue
2. Describe what needs to change
3. A developer will create a PR with the changes
4. After review and merge, the changes go live automatically

## How long does onboarding take?

From issue creation to live website: typically 1-2 weeks, depending on content readiness.

## Can I edit the website myself?

Not directly in this repository. The website is generated from the tenant configuration.
Content changes go through the PR process to ensure quality and compliance.

## What languages are supported?

Lithuanian (lt), English (en), and Russian (ru). Lithuanian is the default for the pilot.

## Who can I contact about data privacy?

Email `dpo@viavitae.com` for any data protection questions.

## What happens when we want to stop using the service?

See the [offboarding runbook](offboarding-runbook.md). Your data is archived for
24 months per GDPR, then permanently erased.
